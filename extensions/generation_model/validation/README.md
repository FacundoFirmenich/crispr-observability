The portable command keeps the initial C/D/U counts and the withdrawn C/D
counts at each donor and stratum. At HG004 chr20:52,989,164 (one-based), ONT
retains a discordant majority and HiFi retains a concordant majority under the
same decision rule. The archived locus position is zero-based (52,989,163).
The genotype comparison operates at donor/locus/library level.

The historical output packages, range-access scripts and recorded freeze
identities are distinct from an offline replay of the decisions. The command
does not regenerate the archived scores from raw alignments. The source
snapshot's cloud custody receipts and manuscript material remain outside
this public integration.
