# Scientific reintegration with the principal CRISPR observability line

The author authorized reintegration on 2026-11-10. The temporary repository split
was a protection against disturbing the established work, not a claim that the
new results were unrelated. The historical main-line releases remain immutable.

## What is already supported

MP27 completed 61,056 records across 818 locus-stage cases, with 854,784 decisions
over seven error budgets and two tract paddings. No in-domain true-history label
was excluded. This is conditional computational validation, not molecular accuracy.
The nonvacuity gate for literal observed-tract certification failed at budget 2.
The constructive insertion/deletion replacement of a required source flank adds
at most two edits while leaving the observed sequence unchanged. Thus literal
source-base ancestry is not identifiable under that permissive history model.

The source-allele endpoint is distinct. Among 720 clean centered heldout reads,
594 had the correct singleton allele set at budget 2 and 126 were ambiguous.
Across all 10,800 heldout reads, including histories outside that budget, there
were 8 wrong singleton allele calls. These adverse cases are retained: an unknown
error budget is a real limitation, not removed by the deterministic theorem.

## Next experiment: MP28

The frozen protocol evaluates locus-block split-conformal source-allele sets on
512 new chr20 loci. It separates matched calibration from noise shift, catalogue
misspecification, catalogue expansion, and recalibration. The endpoint changes
from a fixed deterministic budget to a coverage-calibrated set under explicit
exchangeability assumptions. It does not repair literal base ancestry and does
not supply independent wet-lab validation.

Protocol, calibration thresholds, all outputs, source hashes, and adverse results
are retained. Main-line scientific integration must report the historical failed
gate and the new endpoint together; it must not retroactively change MP27 truth
labels or denominators. Manuscript and supplement files are kept private.

Original extension code is MIT. Existing main-line material and third-party code
retain their respective notices. No blanket relicensing is implied by integration.
