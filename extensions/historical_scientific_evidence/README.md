# Historical scientific evidence extension

This allowlisted archive opens the original scientific results and analysis code
for near-optimal CFTR/HEK3 paths, external K562/HEK3 comparisons, HG002, KEAP1 and
same-fragment identity checks. Every member was read in full from archived
custody and matched the previously recorded SHA-256. Source paths are preserved
to retain scientific lineage. No manuscript, supplementary text, native chat,
unrelated BIO programme, credential or runtime is included.

Historical scripts are preserved rather than silently rewritten. They may rely
on historical directory layouts or external software; distribution and identity
verification do not claim a fresh rerun of each analysis. Original FASTQ sources
and engine prerequisites remain specified in the corresponding acquisition and
freeze records. Retained numerical outputs and individual identities are open.
The separate COL17A1 companion has the new portable quick/full replay entry point.

Original project Python code follows the repository's MIT code license. Source
data and derived records retain original-study attribution and source terms.
Third-party source articles, supplementary documents and upstream R scripts are
not redistributed here. See original studies cited in the acquisition records.
