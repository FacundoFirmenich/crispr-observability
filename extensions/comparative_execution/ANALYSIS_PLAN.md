# Native comparator campaign and donor-held-out decision routing

Frozen before this campaign's new engine outputs, 13 November 2026. Earlier CFTR observations and all historical genotype panels are already known; this is a new retrospective computational experiment, not prospective biological validation. Original-template editing accuracy is outside this release's completion gates by the author's explicit scope decision. Its evidence limit remains unchanged.

## Native engines
Run all nine frozen primary CFTR libraries, not a result-selected subset, through CRISPResso2 2.3.4 dedicated prime-editing mode, ampliCan 1.32.1 and the CRISPR-A pipeline at e5c6c8df1711df6de1f9c3c832ee297d5c48d18d. Input hashes, reference sequences and construct originate in the existing public repository. Common preprocessing is whole-read arithmetic mean Q30. Additional native filtering and trimming are retained and quantified; native pipelines are not silently edited to match our observer.

CRISPResso2 uses its authenticated pegRNA/extension/scaffold/nicking-guide parameters. CRISPR-A uses the same mutant and programmed references in guide orientation, no simulation, no UMI clustering, no self-reference discovery and no spike-in correction. Its default native trimming remains active. ampliCan uses single-end input, the original forward reference, its first 20 bases as a computational assignment anchor (not a claim about the original PCR primer), the authenticated guide with the correct orientation, and the programmed reference as donor. All internal positions are uppercase so event inclusion is not restricted to an inferred DSB window. Use native default mismatch/scoring and event filters; no control subtraction for the primary comparison, to keep the raw event accounting distinct. An empty reverse field represents the actual single-end assay.

Primary outputs: original N, common-Q30 input, additional native exclusions, native event/assignment counts and denominator, computational wall time, peak memory when measurable, versions and image digests. Keep the three preparations and treatment/mock/unmanipulated conditions separate. Native HDR/template/PE classes are named as such; they are not automatically the exact observed-DNA target. Matched event projection is admitted only where source strings, alignment coordinates and record identity can be reconstructed. Otherwise preserve a comparison boundary, not a manufactured common label. No accuracy ranking without suitable labels.

## Local decision routing
Use the existing four-donor, two-tract-stratum homopolymer panel. The action is retain the initial call or apply the already-fixed majority abstention rule. Hold out each donor and learn decisions only from the other donors' cells. Test both pooled routing and tract-specific routing. Candidate discordance/abstention cost ratios are fixed at 2, 4, 6, 10 and 20; report the entire grid. Set abstention cost to one and concordant-call cost to zero. Empirical routing applies the majority rule only if the training loss change is strictly negative; ties retain the baseline. A Beta(1,1) expected-loss sensitivity smooths the discordance probability among withdrawn calls; it is a declared simple prior, not an empirically calibrated probability model.

Report each held-out donor/tract cell, pooled totals, error withdrawals, sacrificed concordances, coverage, retained-call discordance and loss relative to both fixed policies. The four held-out folds cover the same historical panel and are not four independent new studies. Shared loci across individuals and relatedness remain dependence considerations. No cell, cost or rule is removed because of an adverse result. The comparison is exploratory transport of a policy across known germline benchmark donors, not edited-fragment accuracy.
