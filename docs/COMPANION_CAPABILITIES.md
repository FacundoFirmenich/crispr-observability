# An executable research environment

The method, evidence graphs and laboratory form one research workflow:
**locate a claim → inspect its support → alter a declared operation → retain a replay**.

| Component | Research operation | Reusable output | Evidence boundary |
| --- | --- | --- | --- |
| Epistemic Supergraph | Navigate typed support, qualification and revision links; inspect conjunctions; follow a conceptual tour; rearrange cards and columns | Standalone HTML, source JSON, SVG/JSON view exports | Argument navigation; graph geometry does not assign evidence weights |
| Numerical epistemic explorer | Inspect CFTR E/NE/U partitions, hulls, sensitivity and source contracts | CSV/JSON/SVG | Original frozen numerical domain |
| PaperGraph | Read the scientific argument at three depths and distinguish reading order from logical support | Standalone HTML and argument model | Authored explanation; user learning has not been measured |
| Read Observability Lab | Manipulate sequence geometry, inspect 3D structures, compare spans, query local alignments | Case JSON, experiment replay, coordinate TSV, detailed PNG | Declared computational interventions; ideal structure is not physical simulation |
| Multi-input engine | Run study manifests with named sequence, structure and alignment inputs | Structured report via CLI, JavaScript or MCP | Cross-file identity is not a molecule link; browser remains one active case |
| Reproduction workspace | Select quick/counts/full or evidence-family replay; inspect ledger | Execution receipts, reconstructed results, notebook and dashboard | Frozen replay versus fresh acquisition/scoring are separately identified |

## Try the two central mechanisms

1. Open `interactive/lab/CFTR_OBSERVABILITY_LAB.html` and choose **Read boundary**.
   Use anchor [210,222), displacement +3 and read end 224. The result is 11 of
   12 required positions. Change only the end to 225: containment is restored.
   This is a coordinate counterfactual; archived empirical counts do not change.
2. Choose **Competing spans** and the archived 42/87-base case. Inspect each
   extracted string and its exact overlap. A shared event label does not make
   the strings identical.
3. Open the Supergraph and follow the first two conceptual tour blocks. Inspect
   the premises and source artifacts that support each mechanism.
4. Export a laboratory replay and reopen it. Parameters and camera state are
   restored; calculated outputs are recomputed from the inputs.

## Reuse on another study

Use the browser for one active case, or `engine/project-cli.mjs` for a manifest
containing multiple named inputs and operations. The engine supports inspection,
sequence-span comparison, anchor containment, atom distance and alignment-locus
analysis. [The engine guide](../engine/README.md) defines paths, schemas and limits.
[The laboratory guide](../interactive/lab/README.md) defines formats and view controls.
[MCP documentation](../interactive/lab/MCP.md) describes workspace-bound rendering;
the engine guide covers batch execution through `lab_project_run`.

## Source scope and validation

These tools test and expose the contracts they implement. The graph preserves
source identities and conjunctions. Software validation compares coordinate
decoding, replay, API/CLI/MCP results, namespace isolation and selected browser
behaviour. User efficacy and independent molecular accuracy are separate targets.
The integrated checks run in `.github/workflows/community-tools.yml` and retain
their run-specific reports. An existing historical pass is not a new test result.

The existing v0.8.1 DOI and v0.9.0 native packages remain immutable historical
distributions. Current source additions require their own commit citation and
future release archive.
