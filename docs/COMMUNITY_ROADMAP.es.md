# Participación comunitaria y hoja de ruta

[English](COMMUNITY_ROADMAP.md)

La portada bilingüe, el caso guía verificable, la guía de investigación, los
topics, metadatos de citación, CI pública y formularios de incidencias facilitan
el descubrimiento y uso. Son mecanismos de participación, no prueba de adopción.

| Aporte | Entrega mínima útil | Evidencia de aceptación |
| --- | --- | --- |
| Reproducción independiente | Commit, comando, entorno y recibo completo | Resultado recalculado y discrepancias sin cambiar la entrada congelada |
| Nuevo caso | Fuente compartible, procedencia, unidades y pregunta | Resultado trazable e interpretación delimitada |
| Adaptador | Fixture permitido, especificación y campos perdidos | Acuerdo entre formatos y rechazos explícitos |
| Corrección científica | Afirmación, contraejemplo local, fuente y cálculo | Adjudicación reproducible con evidencia adversa conservada |
| Accesibilidad/traducción | Flujo, idioma y texto propuesto | Coherencia terminológica y de instrucciones ejecutables |

Use Issues para fallos concretos y Discussions para preguntas. Los pull requests
se revisan en rama separada, con procedencia/licencia, pruebas pertinentes y
actualización de ambas guías. No publique información clínica identificable ni
datos inéditos ajenos. Registre el estado real de integración de cada capacidad.

Los próximos hitos son reproducción externa independiente, evaluación de tareas
con usuarios, cobertura de fixtures CSI, integración temporal y adjudicación de
edición sobre el fragmento original. No se promete fecha ni resultado favorable.
Los datos grandes pertenecen a archivos científicos apropiados; aquí se conservan
manifiestos y casos pequeños. Las releases deben tener etiqueta, checksums,
licencias, notas y cita versionada. El DOI existente identifica su snapshot.
La difusión directa requiere actuación del autor: no se envían mensajes masivos
ni se fabrica actividad comunitaria.
