# v0.10.0 — From a computational result to a reusable research environment

The public entry point now brings the scientific method, epistemic Supergraph,
Read Observability Lab and scoped reproduction together.

- Integrated v0.5 multi-input engine: six operations, CLI, JavaScript API and MCP.
- Executable CFTR leading case: two authentic reads and seven checked operations.
- Complete researcher/community guides and demo in English and Spanish.
- Explicit reuse states for CRISPR Observability, Biogen/BioGen S1 and ChronoWitness.
- Supergraph: 65 nodes, 67 links, eight original AND gates and nine tour blocks.
- Streamlit includes the laboratory and bilingual guide; Docker includes their inputs.
- Native packages include the laboratory, graph and offline researcher guide.
- Frozen numerical evidence and original disagreement/abstention outcomes retained.

Native binaries are checked on Windows x86-64, Linux x86-64, macOS Intel and
macOS Apple silicon. Build receipts state exact source identity and replay scope.
Large original-data acquisitions and new raw-read scoring remain separate tasks.
No Colab or Kaggle session is started by these tools.

This release contains software and public scientific evidence. Manuscript,
formal supplement and editable manuscript sources remain private. The existing
Zenodo DOI 10.5281/zenodo.24121127 identifies v0.8.1, not this new version.
