# Community participation and development roadmap

[Castellano](COMMUNITY_ROADMAP.es.md)

The repository invites scientific scrutiny and reusable cases. Discoverability
is supported by a bilingual landing page, a verified leading case, a researcher
guide, repository topics, citation metadata, public source CI and reproducible
issue forms. These are participation mechanisms, not evidence of adoption.

| Contribution | Smallest useful submission | Acceptance evidence |
| --- | --- | --- |
| Independent reproduction | Exact commit, command, environment and full receipt | Recomputed result and any discrepancy, without changing the frozen input |
| New scientific case | Shareable source, provenance, coordinate/unit contract and expected question | Traceable output and a scoped interpretation |
| Format adapter | Minimal permitted fixture, conversion specification, loss report | Cross-format agreement and explicit rejected cases |
| Scientific correction | Affected claim, local counterexample, source and calculation | Reproducible adjudication; adverse evidence retained |
| Accessibility/translation | Workflow, language and exact proposed wording | Terminology and executable instructions remain aligned |

Use Issues for actionable defects and Discussions for questions and ideas. Review
pull requests in a separate branch, verify provenance/licensing, run the relevant
checks and update both language guides. Do not post patient information or
unpublished collaborators' data. Maintainers should record integration state and
limitations rather than promise unsupported formats.

Next evidence-bearing milestones are an independent external reproduction,
community user-task evaluation, CSI fixture coverage, temporal-adapter integration
and independent original-fragment editing adjudication. No date or favourable
outcome is promised. Larger datasets should remain in appropriate scientific
archives, with small test cases and manifests here.

Publication-facing releases should have immutable tags, archived source,
checksums, release notes, licence notices and a version-specific citation.
The existing Zenodo DOI remains tied to its archived snapshot. Announcements,
conference submissions and direct outreach require author action; this repository
does not automate unsolicited messages or manufacture engagement.
