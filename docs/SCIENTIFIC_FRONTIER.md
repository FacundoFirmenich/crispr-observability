# Scientific scope and independent verification

The local question is whether a declared event remains comparable when the editing product changes the sequence feature used to observe it. Each result is indexed by raw universe, event definition, observation rule, reference and accepted-label assumptions. A positive contrast does not certify stable per-record labels or molecular correctness.

MP02 used CRISPResso2 2.3.4 at commit `1fc4b629e5400a48d6569b0ab4b8d1766f33636f`. Its separate parameter analysis contains 144 actual jobs: 18 baseline repetitions, 108 one-at-a-time variations and 18 stock-default/no-guide jobs. The default repository replay uses frozen outputs and does not run that grid.

Native software `MODIFIED/aligned` percentages and local exact-sequence or peptide-event bounds on raw records are different estimands. Both baseline projections already support positive PE-minus-mock contrasts; the witness does not own that sign and has not been shown more accurate against molecular truth. Its contribution is a stricter correspondence contract with explicit unknowns.

Within seven one-at-a-time mutant-reference settings, 48 distinct raw IDs switch accepted E/NE labels for each event. Across fourteen reference-setting combinations, conflicting sets contain 161 exact-event and 163 peptide-event IDs. These finite observations establish label sensitivity under tested rules, not every protocol. All tested contrast lower bounds stay positive: aggregate sign and per-record assignment stability are distinct.

The original witness uses the target observer and two baseline projections. It is not retrospectively redefined as a fourteen-setting intersection. An enlarged witness would be a separately versioned observation policy for future use.

## Independent verification protocol

No independent human or biological reproduction is asserted. A third-party analyst can test three distinct capabilities:

1. Run `python3 code/run_review_checks.py` in a fresh checkout; retain commit, environment, stdout/stderr and hashes. This checks arithmetic and raw-observer reconstruction with frozen alignments.
2. Independently install the exact engine, recover raw streams, reproduce baseline commands and compare native totals plus per-record projections. This needs the separate full-engine inputs and command freeze, not only this runner.
3. Compare discordant or unknown records with authenticated orthogonal evidence of the intended molecular object. That can calibrate accuracy; replaying the same assumptions cannot.

Record failures by stream, raw ID, event, reference/window, observed string, accepted status and affected conclusion. Source FASTQ, frozen results and prior decisions stay unchanged. New rules improve future policies; they do not rewrite historical executions as prospectively validated.

## Remaining biological boundary

Coding-string correspondence does not establish full-allele identity, haplotype-specific expression, protein abundance, channel function or injury. Those levels need authenticated sample links and their own measurements. The paper is a bounded methods contribution; it does not collapse the wider programme into this assay or turn a consistency check into an editor improvement.

## PaperGraph: argument visibility, not an added experiment

The MP04 PaperGraph separates the order used to teach a result from the
relationships needed to justify it. For example, anchor geometry motivates
conditional identification analysis but does not empirically prove an interval
formula. A bound needs a declared finite universe, a complete E/NE/U partition,
accepted-label correctness and the stated unknown-completion rule. These
requirements remain visible beside the result at every reading depth.

Equal local labels can coexist with unequal observed coding strings. The
18 equal-label/unequal-string cases reject that particular interchangeability
inference; they do not demonstrate 18 molecular classification errors or prove
that CRISPResso2 fails its own declared target. Similarly, a positive lower
endpoint under each tested alignment profile does not imply stable record
labels or transport beyond the finite tested configurations. The graph preserves
those separate conclusions through typed relations and explicit AND premises.

The public reading model has 12 stations, 49 facts, 92 nodes and 86 links
(75 scientific relations and 11 reading-order links), with seven conjunctions.
These are authored argument objects on the same evidence, not new independent
observations. The complete private article and supplement and their full-text
snapshots are excluded. Public numerical bindings are verifiable in this
repository; withheld text identities cannot be inspected here.

Qualified claim/evidence/argument graphs predate this implementation, notably
Micropublications (Clark, Ciccarese and Goble, 2014;
https://doi.org/10.1186/2041-1480-5-28). The local contribution is an inspectable,
source-bound reading interface for this study. Browser checks establish selected
interface behavior and rendering properties; they cannot demonstrate reader
comprehension or educational efficacy. Those questions require an actual reader
evaluation, while molecular accuracy and function require their own evidence.
